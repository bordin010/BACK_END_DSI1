# JavaScript

## O que é JavaScript?

O **JavaScript** é uma linguagem de programação criada para tornar páginas da internet mais **dinâmicas e interativas**. Com ele, é possível fazer uma página responder às ações do usuário, como cliques, preenchimento de formulários, movimentação do mouse e outras interações.

Ele é uma das principais tecnologias utilizadas no desenvolvimento Web, junto com **HTML** e **CSS**. Enquanto o HTML organiza a estrutura da página e o CSS cuida da aparência, o JavaScript é responsável principalmente pelo **comportamento e pela lógica**.

## História

O JavaScript foi criado em **1995 por Brendan Eich**, enquanto ele trabalhava na empresa **Netscape**. A linguagem foi desenvolvida inicialmente para ser executada dentro dos navegadores e permitir que os sites fossem mais interativos.

No começo, o JavaScript recebeu outros nomes, como **Mocha** e **LiveScript**, até chegar ao nome JavaScript. Apesar do nome parecido, JavaScript e Java são linguagens diferentes.

Com o crescimento da internet, o JavaScript foi adotado por vários navegadores e continuou recebendo melhorias. A linguagem também passou a ser padronizada pelo **ECMAScript**, que define suas principais regras e recursos.

## Como o JavaScript funciona?

O JavaScript pode ser executado diretamente no **navegador**, como Chrome, Edge ou Firefox. Quando uma página possui um código JavaScript, o navegador interpreta e executa esse código.

Ele pode, por exemplo:

* Alterar textos e imagens;
* Modificar elementos HTML e CSS;
* Criar e controlar botões;
* Validar formulários;
* Criar animações;
* Responder a eventos, como cliques;
* Buscar informações de servidores e APIs.

O JavaScript também pode ser executado fora do navegador. Com o **Node.js**, por exemplo, ele pode ser utilizado no desenvolvimento de servidores e sistemas de Back-End.

## Onde o JavaScript é usado?

Apesar de ser muito conhecido pelo desenvolvimento de sites, atualmente o JavaScript pode ser utilizado em diversas áreas:

* 🌐 **Desenvolvimento Web:** criação de sites e aplicações interativas;
* 🖥️ **Back-End:** criação de servidores e APIs com Node.js;
* 📱 **Aplicativos mobile:** desenvolvimento de aplicativos utilizando ferramentas como React Native;
* 🎮 **Jogos:** criação de jogos que podem funcionar diretamente no navegador;
* 💻 **Aplicações desktop:** criação de programas para computadores utilizando tecnologias como Electron.

## Principais características

O JavaScript possui diversos recursos que permitem criar aplicações completas. Entre eles estão:

* **Variáveis:** armazenam informações;
* **Funções:** organizam códigos que realizam determinadas tarefas;
* **Condicionais:** permitem tomar decisões no programa;
* **Loops:** permitem repetir determinadas ações;
* **Arrays:** armazenam vários valores;
* **Objetos:** organizam informações relacionadas;
* **Eventos:** permitem executar ações quando algo acontece;
* **DOM:** permite acessar e modificar elementos HTML.

## Bibliotecas e frameworks

O JavaScript possui um grande ecossistema de bibliotecas e frameworks que facilitam o desenvolvimento. Alguns exemplos conhecidos são **React, Angular e Vue.js**, utilizados principalmente para interfaces, além do **Node.js** e **Express**, muito utilizados no desenvolvimento de Back-End.

## Importância do JavaScript

O JavaScript se tornou uma das linguagens mais importantes do desenvolvimento de software porque pode ser utilizado em diferentes partes de uma aplicação. Ele começou focado na interatividade dos sites, mas evoluiu para uma tecnologia capaz de participar do desenvolvimento de **sites, sistemas, APIs, aplicativos, jogos e servidores**.

Por isso, aprender JavaScript é muito importante para quem deseja trabalhar com **desenvolvimento Web e programação**.
